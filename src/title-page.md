# C++ 到 Rust 常用语法手册

这本书旨在帮助C++程序员学习Rust。它提供了将常见的C++模式翻译成惯用Rust语法的翻译。每个模式都通过具体的代码示例和高级的工程权衡讨论来描述。

本书可以按顺序从前到后阅读，但设计初衷是想查哪里查哪里。
当你编写Rust代码并想，“我知道在C++中怎么做，但不知道如何在Rust中做”时，请查找这本书中相应的章节。

这本书是由布朗大学[Cognitive Engineering Lab](https://cel.cs.brown.edu/)的 C++ 和 Rust 资深程序员手写的。我们的目标是提供准确的信息，并带有适当的细节程度。这本书中的所有文本都不是由AI编写的。

## 其他学习资源

如果您没有任何Rust经验，您可能首先考虑阅读[《Rust编程语言》](https://rust-book.cs.brown.edu/)或快速浏览[Learn X in Y Minutes](https://learnxinyminutes.com/rust/)。

如果您主要使用C或C++进行嵌入式系统编程，这本书是《嵌入式Rust书》（https://docs.rust-embedded.org/book/）的补充。

相较于《Rust奥秘之书》（[Rustonomicon](https://doc.rust-lang.org/nomicon/)）和《通过过多链表学Rust》（[Learn Rust With Entirely Too Many Linked Lists](https://rust-unofficial.github.io/too-many-lists/)）这类教程资料，本书较少探讨“Rust的幕后机制”，而更侧重于以C++为参照系来明确阐述Rust的工作原理。
